# M4a — Library repository bootstrap complete

## Summary

Bootstrapped the sibling `MoBlend_Lib` repository with PRD 7 layout, canonical schemas, `build_index.py` with manifest validation, and the first publishable template (`parametric-cube-demo`). Generated `index.json` contains one catalog entry with absolute raw-Git URLs so M4b can fetch a valid catalog.

## Changes

- `MoBlend_Lib/templates/demo/parametric-cube-demo/` — `.mo.blend`, `.manifest.json`, `.webp` (M1 synthetic template, rebranded)
- `MoBlend_Lib/scripts/bootstrap_parametric_cube_demo.py` — headless Blender generator for the bootstrap template
- `MoBlend_Lib/scripts/build_index.py` — manifest schema validation (jsonschema when available, structural fallback)
- `MoBlend_Lib/index.json` — regenerated with one entry
- `MoBlend_Lib/README.md` — bootstrap instructions and M4a complete status
- `MoBlend_Lib/AGENTS.md` — already present from scaffold

## Decisions

- Bootstrap preview uses static WebP (EEVEE `render_frame`); animated loops deferred to production templates per PRD 7.
- Template binary is generated fresh from `m1_roundtrip._create_minimal_test_template()` (not a mutated temp file) so manifest defaults match authored values.
- `build_index.py` uses structural validation when `jsonschema` is not installed on the host.

## Follow-ups
