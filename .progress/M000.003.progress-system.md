## Summary

Added append-only `.progress/` folder for lightweight context engineering. Agents must record completed work using `{milestone}.{index}.{descriptor}.md` naming; prior progress files are immutable—corrections and regressions are new entries only.

## Changes

- `.progress/README.md` — system specification and entry template
- `.progress/M000.001.*`, `M000.002.*` — backfilled audit entries for prior M0 spec work
- `AGENTS.md` — mandatory progress rules (strict)
- `ROADMAP.md` — pointer to progress log in working convention

## Decisions

- Three-digit index per milestone, monotonic, never reused.
- `.progress/` tracked in git; not gitignored.
- ROADMAP remains the “what/when”; `.progress/` is the immutable “what happened” audit trail.
