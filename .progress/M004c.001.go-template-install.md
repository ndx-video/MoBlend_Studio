# M4c — Go template install complete

## Summary

Added Wails Go bindings to stream library `.mo.blend` binaries into `<moblend_home>/templates/`, record install metadata in `studio.db` `installed_templates`, and skip re-download when `catalog_version` matches an existing on-disk file.

## Changes

- `desktop/internal/store/types.go` — `InstalledTemplate` type
- `desktop/internal/store/studio.go` — `UpsertInstalledTemplate`, `ListInstalledTemplates`, `GetInstalledTemplate`, `DeleteInstalledTemplate`
- `desktop/template_install.go` — download logic (60s timeout, 50MB cap, temp→rename)
- `desktop/app.go` — `InstallTemplate`, `ListInstalledTemplates`, `GetInstalledTemplatePath` bindings
- `desktop/internal/store/store_test.go` — installed_templates CRUD round-trip
- `desktop/template_install_test.go` — httptest install, cache hit, version bump, stale-row prune
- `desktop/frontend/wailsjs/` — regenerated bindings (`wails generate module`)
- `desktop/AGENTS.md` — M4c install surface documented

## Decisions

- Template IDs with slashes map to flat filenames (`/` → `_`) under `templates/`.
- `GetInstalledTemplatePath` prunes stale DB rows when the file is missing or empty.
- `AddRecentProject` after install deferred to M4d per spec.
