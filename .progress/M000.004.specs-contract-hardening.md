# M0 — Specs contract hardening & cleanup

## Summary

Implemented the "Specs Improvement Recommendations" review of `specs/`: closed API-contract gaps, resolved cross-document contradictions, fixed Windows/Unix path inconsistencies, tightened the security model, and improved spec governance. Goal was to give M2/M3 an unambiguous contract before implementation begins.

## Changes

- **`specs/Mo.Blend API & Function Spec.md`** — Added `moblend_list_templates` MCP tool; documented `preset_id` and `engine.list_templates`; added REST endpoints `project/save`, `PATCH /slots`, `GET /templates`, `GET /render/status/{job_id}` (with `result_path`); added a standard error envelope + status/code table; referenced the canonical manifest schema; OS-neutral asset cache path.
- **`specs/manifest.schema.json`** (new) — Canonical JSON Schema (draft 2020-12) for the `.mo.blend` manifest: stable `socket_identifier` (not positional index), fixed `type` enum, `slot_presets`/`slots`, metadata incl. `template_version`. Version pinned to `"1.0"`.
- **`specs/PRD 3 - MCP & API Server.md`** (renamed from `… (Expanded).md`) — Added `moblend_list_templates` to the MCP list; added template-catalog/slots routes; bearer-token auth required for any non-loopback bind; expanded SSRF rules (private/loopback/link-local/metadata blocking + redirect re-validation); WebSocket `protocol_version` byte + `frame_number`↔`time_seconds` reconciliation; unified config filename.
- **`specs/PRD 5 - OBS Extension Panel.md`** (renamed from `… (Expanded).md`) — Versioned all endpoint references (`/api/v1/...`); job-poll flow for render/inject; dual-PC LAN setup now requires `--bind-public` + bearer token; flagged `localStorage` plaintext credential risk.
- **`specs/PRD 1 - Blender Headless Base Compute.md`** — New §2.2 Blender Version Baseline (4.2 LTS+); camera is template-defined (removed forced-orthographic lock); crash-recovery path made absolute; OS-neutral config guidance (security/sandboxing renumbered to §2.3).
- **`specs/PRD 2 - Mo.Blend Python Engine.md`** — Manifest example switched to `socket_identifier`; canonical type list + schema reference; SHA-256 chosen for asset dedup; OS-neutral temp cache.
- **`specs/PRD 4 - Wails Desktop UI.md`** — Parameter-grid mapping references canonical type registry (incl. text/int/bool/image/video/font); unified config-file guidance.
- **`specs/PRD 7 - Template Repository.md`** — CI manifest validation references canonical schema + `socket_identifier`; new Blender-compatibility CI check.
- **`specs/Mo.Blend System PRDs.md`** — Demoted from parallel source of truth to an overview/index (links + brief summaries, per-PRD files authoritative); removed drifting `/inspect` and unversioned `GET /templates` details; retained PRD 8 summary; added a Non-Functional Requirements table.
- **`README.md`, `ROADMAP.md`, `AGENTS.md`** — Updated links to the renamed PRD 3 / PRD 5 files.

## Decisions

- **Single registry-fetch authority:** the broker exposes `GET /api/v1/templates` (cached `index.json`); the Wails Go backend's direct `index.json` fetch is reserved for install/binary streaming only.
- **Auth model:** loopback = no token; `--bind-public` = mandatory bearer token + explicit CORS origin (no wildcards).
- **Manifest binds by stable `socket_identifier`, never positional index.** Manifest schema version is `"1.0"`; template content version is separate (SemVer) in metadata.
- **Blender 4.2 LTS** is the pinned baseline; "Eevee Next" == EEVEE (4.2+).
- **Filename normalization:** dropped the `(Expanded)` suffix from PRD 3 and PRD 5. The link in the immutable `M000.002.websocket-viewport-spec.md` now points to the old name — left untouched per the append-only rule (audit records the name as it was at the time).
