# M3 — E2E suite rewrite and editor MVP hardening

## Summary

Completely rewrote the Playwright E2E suite (11 → 24 tests) with structured fixtures, stateful broker mocks, mock WebSocket viewport frames, and optional live-broker integration tests. Fixed editor gaps for M3: 200ms parameter debouncing per PRD 4 §10.2, dynamic broker URL resolution via Go `GetBrokerBaseURL()`, and stable `data-testid` hooks on all parameter/slot controls. Regenerated the M1 synthetic template via headless Blender to include `slots` and `slot_presets` for timeline testing. All 24 E2E tests pass (22 mocked + 2 live broker).

## Changes

- **Deleted** legacy `e2e/app-shell.spec.ts`, `home-flow.spec.ts`, `editor.spec.ts`, `suite-manager.spec.ts`, `mocks.ts`
- **Added** `e2e/fixtures/manifest.ts`, `e2e/fixtures/mocks.ts` (stateful broker + mock WS JPEG frames)
- **Added** `e2e/helpers.ts`, `e2e/m3-*.spec.ts` (navigation, home, editor, projects, suite-manager, screens, broker-live)
- `desktop/frontend/src/broker/config.ts` — `getBrokerBase()` / `getBrokerWsBase()` from Wails binding
- `desktop/frontend/src/broker/client.ts`, `useViewportStream.ts` — use dynamic broker URL
- `desktop/frontend/src/App.tsx` — 200ms param debounce, `param-row-*` / `param-input-*` / `slot-row-*` testids
- `engine/tests/m1_roundtrip.py` — default `slots` + `slot_presets` in synthetic manifest

## Decisions

- E2E uses **mocked broker by default** for fast iteration; `m3-broker-live.spec.ts` auto-skips when `:8000` is down
- Mock WebSocket returns minimal valid JPEG FRAME payloads so viewport "WS live" and request-frame flows are testable without Blender
- Parameter debounce verified via **text input** (range sliders don't fire React onChange from synthetic DOM events)
- Blender MCP not added to harness — local `blender.exe --python engine/tests/m1_roundtrip.py` is sufficient for template generation; official Blender MCP is addon-based (blender.org/lab) and out of M3 scope
- Live broker template reload required after m1_roundtrip regen to pick up new slots (`POST /project/load`)
