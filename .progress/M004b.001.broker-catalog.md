# M4b — Broker catalog cache complete

## Summary

Replaced the `GET /api/v1/templates` stub with a real catalog service. The broker fetches `index.json` from `registryBaseUrl` (or reads `catalogFixturePath` for offline dev), caches the body under `<moblend_home>/catalog/index.json`, records metadata in `broker.db` `catalog_cache`, and serves the flattened `templates` array.

## Changes

- `engine/moblend/catalog.py` — `resolve_registry_url`, `fetch_catalog`, `load_cached_catalog`; TTL refresh, ETag/304, stale-serve on failure
- `engine/moblend/store.py` — `get_catalog_cache`, `upsert_catalog_cache`
- `engine/moblend/server.py` — wired `GET /api/v1/templates?refresh=1`, `POST /api/v1/templates/refresh`
- `engine/tests/fixtures/catalog_index.json` — one-entry fixture (parametric-cube-demo)
- `engine/tests/m4_catalog_test.py` — host-Python tests (fixture fetch, TTL hit, stale-serve, shape validation)
- `engine/AGENTS.md` — catalog module note

## Decisions

- Total failure (no cache, fetch fails): `200 OK` with `[]` and `catalog.fetch_failed` log — keeps gallery clients resilient; strict `503` deferred.
- No new pip deps; structural validation of catalog entries in Python (no jsonschema in broker path).
- Default `registryBaseUrl`: `https://raw.githubusercontent.com/ndx-video/MoBlend_Lib/main`.
