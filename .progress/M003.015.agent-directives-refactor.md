# M3 — Agent directives refactor (scope by address)

## Summary

Refactored bloated root `AGENTS.md` into mechanical boundaries: nested `AGENTS.md` per package, path-glob rules in `.claude/rules/` and `.cursor/rules/`, and multi-step procedures extracted to `.claude/skills/`. Root file now holds only global architecture rules and a configuration map.

## Changes

- `AGENTS.md` — slimmed from ~95 to ~75 lines; removed per-package conventions and progress checklist
- `CLAUDE.md` — imports `@AGENTS.md` + pointer to scoped layout
- `desktop/AGENTS.md` — new nested guide (Wails architecture, dev, E2E pointer)
- `engine/AGENTS.md` — new nested guide (bpy runtime, threading, verification)
- `.progress/AGENTS.md` — new nested guide (append-only rules summary)
- `.claude/rules/` — `frontend.md`, `go-desktop.md`, `python-engine.md`, `clients-web.md` with `paths` globs
- `.cursor/rules/` — matching `.mdc` rules with `globs` frontmatter
- `.claude/skills/` — `write-progress-entry`, `desktop-e2e-verify`, `engine-verify` with `paths`
- `scripts/verify-directive-scope.ps1` — dry-check simulator for load reasons

## Decisions

- Scope is an address: nested `AGENTS.md` for directory ownership; `paths`/`globs` for extension-scattered rules; skills for checklists.
- Progress log immutability rules stay authoritative in `.progress/README.md`; `AGENTS.md` there is the agent-facing summary.
- `desktop/README.md` and `engine/README.md` remain human-oriented; agent conventions moved to `AGENTS.md` + rules.

## Follow-ups

- None required. Monitor agent adherence; add path-scoped rules only when repeated mistakes appear.
