# M3 — Flow checkpoints + no silent hangs

## Summary

Status bar stuck on "Opening editor…" and black viewport were symptoms of **silent long-running operations** (`ensureBroker`, `loadProject`) with no per-step feedback or timeouts. Added numbered checkpoints, `FlowError`, HTTP timeouts, skip-redundant template reload, and editor viewport diagnostics on the status bar.

## Changes

| Area | Detail |
|------|--------|
| `util/flow.ts` | `runStep`, `withTimeout`, `FlowError`, `logCheckpoint` → console |
| `broker/client.ts` | AbortController timeouts; errors include path and timeout ms |
| `StatusContext.tsx` | `[1/3]`…`[3/3]` broker steps; shared `ensurePromiseRef` (no duplicate 60s waits) |
| `App.tsx` Home | `[open 1/4]`…`[4/4]`; skip `loadProject` if broker `health.loaded` |
| `App.tsx` Editor | Manifest via `runStep`; status bar reports WS/paint/bytes at each stage |
| `useViewportStream.ts` | Decode WS ERROR text; paint via data-URL first; `bytesReceived`, `lastPaintError` |

## Status bar messages (editor)

Examples users should now see instead of a frozen generic line:

- `[open 3/4] Template already on broker — skipping reload`
- `[editor] Viewport: connecting WebSocket…`
- `[editor] Frames received (4567 B, f0) but canvas not painted: …`
- `[editor] Preview live — 8.2 fps, 12 painted`

Double-click status bar copies full checkpoint history for debugging.
