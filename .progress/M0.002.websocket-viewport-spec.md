# M0 — WebSocket viewport protocol (gRPC demoted)

- **File:** `M0.002.websocket-viewport-spec.md`
- **Date:** 2026-06-14
- **Milestone:** M0 — Specs & Scaffold
- **Related commits:** `6f24ed7`

## Summary

After architecture review, adopted **binary WebSocket** as the v1 viewport data plane on the FastAPI broker (`ws://127.0.0.1:8000/api/v1/viewport/stream`). gRPC is reserved for a future Kubernetes worker-to-worker path only—not for Wails, OBS, or Sentinel browser clients. Documented wire format, platform targets (Windows primary), AGENTS.md, CLAUDE.md, and expanded `.gitignore`.

## Changes

- `specs/PRD 3` §3.2 — REQUEST_FRAME / FRAME / ERROR binary protocol
- `specs/Mo.Blend API & Function Spec.md` — WebSocket endpoint; gRPC future-only note
- `specs/PRD 4`, `PRD 6`, System PRDs — client connection rules (direct webview WS, not Go bindings)
- `specs/PRD 1`, `PRD 4` — Windows/Linux/macOS Apple Silicon priority table
- `AGENTS.md`, `CLAUDE.md`, `README.md`, `ROADMAP.md` (M2 criteria), `.gitignore`

## Decisions

- JPEG still frames for opaque preview; WebP when alpha required.
- Wails frontend must not proxy frames through Go bindings (base64 IPC overhead).
- Windows (x64) is primary dev/CI target; Linux and Apple Silicon parity as needed.
