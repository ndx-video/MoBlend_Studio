# M3 — Drag-and-drop asset ingest (sandbox → broker → UI)

## Summary

Closed the last open M3 ROADMAP gate: drag-drop (or file picker) → Go sandbox copy → React PATCH `/api/v1/parameters` → `engine.ingest_asset`. Wired PRD 4 §6.4 end-to-end in Mo.Blend Studio with Editor asset controls, a functional Assets screen, global Wails drop handling (Option A: auto-ingest when one matching param, modal when multiple), and Playwright E2E coverage.

## Changes

- **Go (`desktop/app.go`)**: Fixed `OnFileDrop` to emit **sandbox paths** from `CopyToAssetSandbox` return value; added `ListAssetSandbox()` and `PickAssetFile(kind)`; refactored `assetSandboxDir()` helper.
- **Wails bindings (`desktop/frontend/wailsjs/go/main/App.*`)**: Regenerated stubs for new Go methods.
- **Shared util (`desktop/frontend/src/util/assets.ts`)**: `ASSET_EXTENSIONS`, `inferAssetKind`, `copyToSandbox`, `ingestAssetParam`, `copyAndIngestAsset` with `runStep` / `FlowError` checkpoints.
- **UI**: `AssetParamRow`, `AssetAssignModal`, `AssetDropContext` (global `moblend:assets:updated` listener); Editor inspector branches for `image`/`video`/`font`; Assets screen lists sandbox files with param assign + ingest; Editor viewport status no longer overwrites `error`-level asset messages.
- **E2E**: `e2e/m3-assets.spec.ts`; `manifest.ts` adds `logo` image param; `mocks.ts` deterministic sandbox paths, functional `EventsOnMultiple`/`EventsOn`, `ListAssetSandbox`/`PickAssetFile`; `m3-screens.spec.ts` copy update.

## Decisions

- **Drop targeting (MVP)**: Option A — window-level Wails drop auto-ingests when exactly one manifest asset param matches the file kind; multiple asset params open an assign modal. Per-param “Choose file…” uses Go `PickAssetFile` in production Wails; HTML file input retained as dev fallback.
- **Path contract**: Absolute filesystem path string in PATCH body (MVP); frontend `normalizePath()` strips optional `file://` prefix only.
- **M1 template**: E2E uses mocked `logo` image param; live broker ingest on M1 GN may no-op without image socket — acceptable for M3 gate; optional follow-up to add socket in `m1_roundtrip.py`.

## Follow-ups

- Thumbnails / URL fetch / registry (M4+).
