# M3 — Status bar clipboard + broker probe hardening

## Summary

Status bar now keeps a message history and supports clipboard copy. Broker detection was hardened so startup is not falsely reported as unreachable, and `StartEngine` errors surface in the log instead of being swallowed.

## Clipboard UX

| Gesture | Action |
|---------|--------|
| Single click | Copy current status message |
| Double click | Copy full timestamped log (`[HH:MM:SS] level: message` per line) |

Brief “Copied” / “Copied full log” flash in the bar. Tooltip: “Click to copy message · Double-click to copy full log”.

## Broker fixes

1. **`probeBroker()`** — tries Go `EngineHealth`, then direct `fetch /api/v1/health` (catches cases where bindings and browser disagree).
2. **`isBrokerUp()`** — treats live health JSON (`loaded`/`dirty`/`template_id`) and `_direct` fetch success as connected; not only `status: 'ok'`.
3. **Background poll** — skips `refreshBroker` while `startingRef` is set so the dot stays yellow during startup instead of flipping red.
4. **Startup errors** — `startEngine('')` failures (e.g. Blender not found) are logged to history instead of `.catch(() => {})`.
5. **Failure detail** — final unreachable message includes underlying error text for paste into bug reports.
