# M3 — Black viewport: broken M1 geometry nodes (0 verts)

## Summary

Status showed "Preview live" and `painted 198` but the viewport was black because **EEVEE was rendering valid JPEGs of an empty scene** — not a canvas/WebView2 bug. The M1 test template's Geometry Nodes modifier had no **Geometry INPUT** socket and wired `Intensity` (float) to `Scale` without passing mesh data. Evaluated vertex count was **0**.

## Root cause

```
eval_verts 0   # before fix
brightness samples: 0,0,0,...  # all black JPEG pixels
```

Frontend decode/paint was working; Blender had nothing visible to render.

## Fixes

| File | Change |
|------|--------|
| `engine/tests/m1_roundtrip.py` | Add GN Geometry IN/OUT; wire `Geometry→Transform→Geometry`; Intensity→Scale; world bg; pre-save vert count assert |
| `engine/moblend/engine.py` | `flag_depsgraph_update()` before `write_still` |
| `App.tsx` | Open in Editor **always** `loadProject` when path known (picks up regenerated `.mo.blend`) |

## Verification (after regen)

```
eval_verts 8
bytes 9544
brightness: 53,53,53,140,48,48,53,53,53
```

M1 roundtrip: **PASS**

## User action

1. Template already regenerated at `%TEMP%\m1_minimal_test.mo.blend` (agent ran `m1_roundtrip.py`)
2. Restart broker or click **Open in Editor** (forces reload)
3. Restart `wails dev` if needed
