# M0 — Zero-pad milestone token in progress filenames

## Summary

Changed the `.progress/` filename convention so the milestone token is `M` + the ROADMAP milestone number **zero-padded to three digits** (`M0` → `M000`). Renamed the six existing `M0.*` entries to `M000.*` and updated their internal self-references and cross-links. This is a deliberate, user-authorized convention migration — the only sanctioned exception to the append-only/immutability rule, performed as filename moves plus link-integrity fixes (no historical narrative was rewritten).

## Changes

- **Renamed** `.progress/M0.001`–`M0.006` → `.progress/M000.001`–`M000.006` (via `git mv`).
- **Updated** each renamed entry's `**File:**` self-reference and inter-entry markdown links (`M0.0NN` → `M000.0NN`).
- **`.progress/README.md`** — milestone segment now specifies three-digit zero-padding; updated full example, M9 example, and the `ls` hint. Added a note that only the filename token is padded (prose milestone references keep the ROADMAP short form).
- **`AGENTS.md`**, **`ROADMAP.md`** — updated progress-filename examples to the padded form.

## Decisions

- Only the **filename** milestone token is zero-padded. Roadmap milestone names (`M0 — Specs & Scaffold`) and the `**Milestone:**` line inside entries keep the ROADMAP's short form.
- Index segment is unchanged (still three digits per milestone).

## Follow-ups

- None. Future entries use `M00N.NNN.descriptor.md`.
