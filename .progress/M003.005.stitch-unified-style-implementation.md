# M3 — Stitch designs implemented as unified source-of-truth style for all UI pages and elements

## Summary

Per user direction and PRD 4 + specs/stitch/README.md: the Stitch exports are the source of truth for appearance/styling (tokens from DESIGN.md YAML + prose, layout structure from code.html reference and screen.png for QA). Functionality is not limited by the illustrative elements in the designs.

Fully explored the stitch/ folder (7 screens). Extracted and applied a single unified style system (enhanced tokens.css with all component styles from the "Components" sections and prose: buttons primary/ghost/icon, inputs, 32px list-item rows with selection accent, panels with 1px borders + tonal elevation, timeline with blocks + diamond keyframes, label-caps sections, gallery cards, pro density, Inter + JetBrains Mono, 4px spacing, rounded values, etc.).

Refactored AppShell (shared left nav rail) and all 7 pages (Home, Projects, Assets, Editor, Export, Suite Manager, User Settings) in the React UI to use the Stitch-driven classes and layout patterns (left sidebar + center + right inspector + bottom docked timeline for edit; card galleries for home; tight lists for projects/assets; etc.). Kept and enhanced all M3 live functionality (auto default template pre-load on broker attach/start, direct broker WS/REST, param grid, slot timeline with drag, export 202+poll, engine start/stop, recents, etc.).

Used E2E (Playwright) extensively for verification during the overhaul (ran multiple times; updated tests to match new Stitch-aligned text/structure; core "no blank pages" + navigation tests confirm all pages render visible content).

Current UI now has consistent pro-tool corporate-modern dark appearance dictated by Stitch across every page and element.

## Decisions

- Unified style means one tokens.css + consistent class usage (no more per-screen inline hex or old styles).
- Appearance strictly from Stitch (palette, 4px unit, panel 1px borders #2D2E35, 32px rows, diamond keyframes, label-caps, pro density, Inter/JetBrains, primary gradient accents on key actions, tonal layers).
- Functionality kept/enhanced (auto-load default on Go broker start/attach, live PATCH/WS, slot drag updating backend, etc.) — designs are illustrative for buttons/UI collections.
- E2E used as the verification tool for GUI (per project convention established in M003.003); tests updated as part of the work.
- No copy of code.html (translated structure to our React + tokens + Lucide icons).
